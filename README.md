# ARCHI-FIT — Parametric 2D CAD & 3D Test Fit Studio

Real-time cross-platform 2D CAD & 3D WebGL Architectural Test Fit Studio for Hotel, Residential, Retail, and Office feasibility studies with live fire egress & mullion grid snap checks.

## Quick Start
Open `index.html` directly in any modern browser on Desktop PC, Tablet, or Mobile, or enable **GitHub Pages** (`Settings -> Pages -> main / root`).
