# ARCHI-FIT — Parametric 2D CAD & 3D Test Fit Studio

Real-time browser-based **2D CAD & 3D WebGL Parametric Test Fit Studio** for **Hotel**, **Residential**, **Retail**, and **Office** architectural feasibility studies.

## Features
- **Dual 2D CAD + 3D WebGL Viewport** (2D Plan, Split View, and 3D Massing)
- **Fire Egress & Dead-End Corridor Verification** (NFPA / IBC code checks)
- **Facade Mullion Grid Snap** (1.20m / 1.35m / 1.50m curtain wall module alignment)
- **Cross-Platform Responsive UI** (Desktop PC, Tablet, and Mobile touch gestures)
- **UTF-8 CSV Space Program Export**

## Quick Start
Open `index.html` directly in any modern browser or deploy via **GitHub Pages**.
