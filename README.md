# ARCHI-FIT — Parametric Architectural Test Fit Studio

**ARCHI-FIT** is a real-time, browser-based **2D CAD & 3D WebGL Parametric Test Fit Studio** built for architects, interior designers, and real estate feasibility analysts across **Desktop PC, Tablet, and Mobile**.

## Key Features
- **Dual 2D CAD Plan & 3D Massing Viewport:** Switch seamlessly between `2D CAD`, `Split View`, and `3D Massing` with structural grid bubbles, dimension strings, and raycaster room inspection.
- **4 Building Typologies:** Hotel & Hospitality, Residential / Condominium, Retail / Commercial Mall, and Office Workplace.
- **Code & Constructability Checks:** Real-time **Max Fire Egress Travel Distance** (`45m` / `60m` sprinklered), **Dead-End Corridor** limit (`15m`), and **Facade Mullion Grid Snap** (`1.20m`, `1.35m`, `1.50m`).
- **Cross-Platform Multi-Touch & PWA:** Pinch-to-zoom, 2-finger pan, responsive mobile bottom-sheet drawer, and UTF-8 CSV Space Program export.

## Quick Start
Open `index.html` directly in any modern browser or enable **GitHub Pages** (`Settings -> Pages -> Deploy from main branch`) for a live web URL.
